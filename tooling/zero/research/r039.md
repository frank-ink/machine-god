# Q
Does provenance-aware selective retrieval with test-gated checkpoints improve multi-day autonomous coding resolution rate versus memory-disabled baselines, and by how many percentage points on SWE-bench Verified?

# A
Provenance-aware memory + test-gated checkpoints: empirical evidence (2024–2026)

Answer: Partially. Selective memory retrieval improves SWE-bench Verified resolution in several experiments. However, no verified controlled study isolates the combined effect of provenance-aware retrieval, test-gated checkpoints and multi-day execution against a memory-disabled baseline.

2. Important counterevidence

VibeMemBench — Fan et al. (2026):

111 coding targets, 90 repositories, 3,634 historical trajectories.

Curated verified memories produced improvements of 1.1–4.5 percentage points in four of five evaluated solvers.

11/12 automatically constructed memory-system configurations failed to outperform memory-off baselines.

This benchmark uses SWE-rebench V2, not SWE-bench Verified. 
arXiv

3. What remains unproven?

There is no defensible numerical estimate for the complete combination:

Provenance-aware retrieval + selective memory + test-gated checkpoints + multi-day autonomous execution

Existing studies generally evaluate repository-level task resolution rather than uninterrupted multi-day operation.

Conclusion: Published SWE-bench Verified improvements range from +4.7 pp for subtask-aligned memory to +21.6 pp for a combined memory/training system. Neither establishes the gain attributable to the requested full architecture.

Main risk: Retrieved memories can reinforce incorrect assumptions while passing tests validate only incomplete task specifications.
