3. Minimum qualifying experiment

Pre-register 200–400 held-out coding tasks. Use identical free-pool backends, with and without the local router.

Fix GPU, model revision, quantization, runtime, tool permissions, budgets and rate-limit conditions. Run randomized paired trials with independent workspaces.

Publish JSONL containing task_id, route, timestamps, backend, tool calls, completion status, latency and hidden-test outcome.

Report p50/p99 end-to-end latency with bootstrap 95% confidence intervals, routing accuracy against a pre-specified oracle, and paired task-success differences.

Conclusion: Small-model routing is empirically plausible. Its latency advantage and accuracy relative to the specified free-pool baseline remain unverified. No defensible numerical p50/p99 result can currently be assigned to this configuration.
