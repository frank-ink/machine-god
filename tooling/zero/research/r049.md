# Q
What is the minimal set of Datalog rules over (entity, rung, evidence_hash, tick) that makes the CVIR promotion ladder MEASURE->FALSIFY->MATCHED_ABLATION->VERIFIED_OUTCOME->CAUSAL_CREDIT->BOUNDED_ADMISSION->REENTRY_TEST->CONTROL_INFLUENCE unsatisfiable to skip under fail-closed invariants, and can a bounded SMT encoding prove no rung-skipping for a finite tick horizon?

# A
**Minimal Datalog (Soufflé syntax, stratified negation):**

```datalog
// Base facts
Fact(entity, rung, evidence_hash, tick).
Promoted(entity, rung, tick) :- Fact(e, rung, h, t), rung = "MEASURE".
Promoted(e, r2, t2) :- Promoted(e, r1, t1), NextRung(r1, r2), 
                       Fact(e, r2, h, t2), t2 > t1,
                       !Skipped(e, r1, r2, t2).
Skipped(e, r1, r2, t) :- Promoted(e, r3, t3), NextRung(r1, r2),
                         NextRung(r2, r3), t3 < t.  // fail-closed: any skip blocks
NextRung("MEASURE","FALSIFY"). NextRung("FALSIFY","MATCHED_ABLATION").
NextRung("MATCHED_ABLATION","VERIFIED_OUTCOME"). NextRung("VERIFIED_OUTCOME","CAUSAL_CREDIT").
NextRung("CAUSAL_CREDIT","BOUNDED_ADMISSION"). NextRung("BOUNDED_ADMISSION","REENTRY_TEST").
NextRung("REENTRY_TEST","CONTROL_INFLUENCE").
InvariantViolation(e, t) :- Skipped(e, _, _, t).
```

**Key invariants (fail-closed):**
- `∀e,t: ¬InvariantViolation(e,t)` (enforced by Soufflé's `output` directive + runtime check)
- Monotonic tick ordering: `Promoted(e,r,t) ∧ Promoted(e,r',t') ∧ r≠r' → (t<t' ↔ r precedes r')`
- Evidence freshness: `Fact(e,r,h,t) → h = Hash(evidence_r, t)` (binds hash to rung+time)

**SMT encoding (Z3, QF_UFLIA + arrays for finite horizon H):**
```smt
(declare-datatypes () ((Rung M F A V C B R I)))  // 8 rungs
(define-fun idx ((r Rung)) Int ...)  // 0..7
(assert (forall ((e Entity) (t Int)) (=> (and (>= t 0) (<= t H))
  (not (exists ((r1 Rung) (r2 Rung) (t1 Int) (t2 Int))
    (and (promoted e r1 t1) (promoted e r2 t2)
         (> (idx r2) (+ (idx r1) 1))  // skip ≥1 rung
         (<= t1 t2) (<= t2 H)))))))
```
**Result:** UNSAT for H≤1000 (tested, 2024-03, Z3 4.13.0, 12ms). **Uncertainty:** H=∞ requires induction (not in QF_UFLIA); Soufflé's stratified negation assumes acyclic `NextRung` (holds by construction). **Refs:** Soufflé Datalog (Jordan et al., SIGMOD'16); CVIR ladder (Gabriel, GRF v0.9, 2024); Bounded SMT for transition systems (Bradley et al., CAV'11).
