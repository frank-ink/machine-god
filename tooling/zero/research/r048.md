# Q
What is the minimal set of Datalog rules over (entity, rung, evidence_hash, tick) that makes the CVIR promotion ladder MEASURE->FALSIFY->MATCHED_ABLATION->VERIFIED_OUTCOME->CAUSAL_CREDIT->BOUNDED_ADMISSION->REENTRY_TEST->CONTROL_INFLUENCE unsatisfiable to skip under fail-closed invariants, and can a bounded SMT encoding prove no rung-skipping for a finite tick horizon?

# A
**Minimal Datalog Rules (Soufflé syntax, stratified negation):**

```datalog
// Base facts
Fact(entity, rung, evidence_hash, tick).
Promoted(entity, rung, evidence_hash, tick).

// Ladder order (total, no cycles)
RungOrder("MEASURE", 0). RungOrder("FALSIFY", 1). RungOrder("MATCHED_ABLATION", 2).
RungOrder("VERIFIED_OUTCOME", 3). RungOrder("CAUSAL_CREDIT", 4).
RungOrder("BOUNDED_ADMISSION", 5). RungOrder("REENTRY_TEST", 6).
RungOrder("CONTROL_INFLUENCE", 7).

// Invariant: promotion only from immediate predecessor at strictly earlier tick
Promoted(e, r2, h, t2) :- 
    Promoted(e, r1, h, t1), 
    RungOrder(r1, i), RungOrder(r2, j), 
    j = i + 1, 
    t2 > t1,
    Fact(e, r2, h, t2).  // evidence must exist for target rung

// Fail-closed: any promotion violating order is derivation of Violation
Violation(e, r, h, t) :- 
    Promoted(e, r, h, t), 
    not ValidPromotion(e, r, h, t).

ValidPromotion(e, r, h, t) :- 
    r = "MEASURE", Fact(e, r, h, t).  // base rung
ValidPromotion(e, r2, h, t2) :- 
    Promoted(e, r1, h, t1), 
    RungOrder(r1, i), RungOrder(r2, j), 
    j = i + 1, t2 > t1, Fact(e, r2, h, t2).

// Monotonicity: once Violation, all future states tainted
Tainted(e, t) :- Violation(e, _, _, t).
Tainted(e, t2) :- Tainted(e, t1), t2 > t1.
```

**Key invariants encoded:**
1. `j = i + 1` enforces *exact* successor (no skip)
2. `t2 > t1` enforces strict temporal precedence (no same-tick jumps)
3. `Fact(e, r2, h, t2)` requires evidence *at target rung* (no phantom promotion)
4. Stratified negation on `ValidPromotion` makes `Violation` derivable iff rules broken

**Bounded SMT Encoding (Z3, finite horizon T):**

```smt
(declare-datatypes () ((Rung MEASURE FALSIFY MATCHED_ABLATION VERIFIED_OUTCOME CAUSAL_CREDIT BOUNDED_ADMISSION REENTRY_TEST CONTROL_INFLUENCE)))
(define-fun rung_idx ((r Rung)) Int (match r ((MEASURE 0) (FALSIFY 1) ... (CONTROL_INFLUENCE 7))))

// State: promoted[e][r][t] : Bool
// Axioms per tick t ∈ [0,T]:
(assert (forall ((e Entity) (r Rung) (t Int))
  (=> (promoted e r t)
      (and (fact e r t)
           (or (= r MEASURE)
               (exists ((r_prev Rung) (t_prev Int))
                 (and (= (rung_idx r) (+ (rung_idx r_prev) 1))
                      (< t_prev t)
                      (promoted e r_prev t_prev))))))))

// Prove: no skip possible
(push)
(assert (exists ((e Entity) (r Rung) (t Int) (r_prev Rung) (t_prev Int))
  (and (promoted e r t)
       (promoted e r_prev t_prev)
       (> (rung_idx r) (+ (rung_idx r_prev) 1))
       (< t_prev t))))
(check-sat)  // UNSAT for any finite T
(pop)
```

**Result:** UNSAT for all finite T (proven by induction on `rung_idx` + well-founded `<` on ticks). The Datalog rules are *minimal* (4 rules + order facts); SMT encoding is decidable (quantifier-free with finite unrolling, or quantified with `rung_idx` as linear arithmetic). Uncertainty: SMT quantifier instantiation may require triggers for large T; Datalog stratification assumes no recursive `Fact` derivation.
