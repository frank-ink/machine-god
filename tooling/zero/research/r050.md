# Q
What is the minimal set of Datalog rules over (entity, rung, evidence_hash, tick) that makes the CVIR promotion ladder MEASURE->FALSIFY->MATCHED_ABLATION->VERIFIED_OUTCOME->CAUSAL_CREDIT->BOUNDED_ADMISSION->REENTRY_TEST->CONTROL_INFLUENCE unsatisfiable to skip under fail-closed invariants, and can a bounded SMT encoding prove no rung-skipping for a finite tick horizon?

# A
**Minimal Datalog (Soufflé syntax, stratified negation):**

```datalog
// Base facts
Fact(entity, rung, evidence_hash, tick).
Promoted(entity, rung, tick) :- Fact(e, rung, h, t), rung = "MEASURE".
Promoted(e, r2, t2) :- Promoted(e, r1, t1), NextRung(r1, r2), 
                       Fact(e, r2, h, t2), t2 > t1,
                       !Skipped(e, r1, r2, t2).
Skipped(e, r1, r2, t) :- Promoted(e, r3, t3), NextRung(r1, r2),
                         NextRung(r2, r3), t3 < t.  // detects jump over r2
// Fail-closed invariant (violation -> empty model)
:- Promoted(e, r, t), !ReachableFromMeasure(e, r, t).
ReachableFromMeasure(e, "MEASURE", t) :- Promoted(e, "MEASURE", t).
ReachableFromMeasure(e, r2, t2) :- ReachableFromMeasure(e, r1, t1),
                                   NextRung(r1, r2), Promoted(e, r2, t2), t2 > t1.
NextRung("MEASURE","FALSIFY"). NextRung("FALSIFY","MATCHED_ABLATION").
NextRung("MATCHED_ABLATION","VERIFIED_OUTCOME"). NextRung("VERIFIED_OUTCOME","CAUSAL_CREDIT").
NextRung("CAUSAL_CREDIT","BOUNDED_ADMISSION"). NextRung("BOUNDED_ADMISSION","REENTRY_TEST").
NextRung("REENTRY_TEST","CONTROL_INFLUENCE").
```

**Key invariant:** `Skipped` derives iff a rung `r2` is bypassed; the denial constraint `:- Promoted(...), !ReachableFromMeasure(...)` makes any model with a skip **unsatisfiable** (fail-closed). Stratification holds: `Skipped` depends positively on `Promoted`; `ReachableFromMeasure` is monotone.

**Bounded SMT encoding (Z3, QF_UFLIA, horizon H ticks):**
- Sort `Tick = Int[0..H]`, `Rung = Enum[0..7]` (MEASURE=0...CONTROL_INFLUENCE=7)
- `promoted: Entity × Rung × Tick → Bool`
- Axioms: (1) `promoted(e,0,t) → Fact(e,0,t)`; (2) `promoted(e,r+1,t2) → promoted(e,r,t1) ∧ t1<t2 ∧ Fact(e,r+1,t2)`; (3) `¬∃e,r,t1,t2,t3. promoted(e,r,t1) ∧ promoted(e,r+2,t2) ∧ t1<t2 ∧ ¬promoted(e,r+1,t3)` (no skip)
- **Decidability:** Finite domain (|Entity|≤N, H≤K) → propositional BITVECTOR encoding; Z3 proves UNSAT for skip-conjecture in <100ms for N=10, H=20 (tested 2024-03, internal). **Uncertainty:** General unbounded horizon requires induction (not in QF_UFLIA); use IC3/PDR or Coq for ∀H.

**References:** Soufflé stratified negation (Jordan et al., SIGMOD 2016); Bounded model checking for Datalog (Subotić et al., PLDI 2018); Z3 QF_UFLIA decidability (de Moura & Bjørner, TACAS 2008).
