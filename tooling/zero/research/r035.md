3. Minimum qualifying ablation

Pre-register N≥200 paired held-out coding tasks, a three-class routing oracle, and fixed model revisions, quantization, hardware, tool permissions and execution budgets.

Compare free-pool alone against the same pool preceded by a local classifier. Randomize execution order and isolate repositories.

Publish JSONL records containing task ID, oracle route, predicted route, timestamps, backend, tool trajectory, hidden-test outcome and failures.

Report end-to-end p50/p99 with bootstrap 95% confidence intervals, macro-F1, routing accuracy, task success and paired differences.

Conclusion: Existing studies establish the feasibility of small routing models, but not their latency or accuracy advantage in the specified architecture. Router-only measurements cannot substitute for end-to-end results.
