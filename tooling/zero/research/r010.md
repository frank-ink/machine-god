# Q
How to design a bitwise-deterministic CVIR admission gate over SQLite receipt tables that guarantees identical decision hashes across 1000 seeded shuffles and process restarts, including canonicalization of field order, integer encoding, and hash chaining?

# A
CVIR: Bitwise-deterministic admission gate

Objective: Identical logical receipt sets must produce identical admission decisions and SHA-256 hashes, independent of SQLite insertion order, Rust process restarts, or Datalog evaluation order.

Architecture: SQLite immutable receipts → canonicalization → signature verification → consistency checks → Ascent policy evaluation → fail-closed Rust admission → deterministic decision hash.

1. Canonical binary format

Use a versioned, explicitly specified encoding rather than SQLite's physical representation.

Use fixed field order, reject invalid encodings and exclude database row IDs, timestamps and insertion sequence.

Sign the canonical payload excluding the signature. Pin trust roots and signature algorithms.

3. Fail-closed Rust admission

Within BEGIN IMMEDIATE, freeze logical tick T, freshness window, policy hash, trust-root hash and request parameters.

Evaluate every receipt before deciding; avoid insertion-order-dependent early exits.

Reject admission if:

tick > T or tick < T − TTL.

Signature, schema or evidence binding fails.

Contradictory PASS/FAIL/REVOKE receipts exist.

Any prerequisite in the eight-stage CVIR ladder is missing.

The evidence snapshot is incomplete or inconsistent.

4. Deterministic replay: 1,000 seeded permutations

Test: cvir_permutation_restart_1000

Generate one fixed corpus with valid, stale, future, duplicate, contradictory and revoked receipts.

For seeds 0..999:

Shuffle insertion order into a fresh SQLite database.

Restart the Rust admission process.

Replay identical requests under identical logical state.

Compare canonical decision bytes and SHA-256 hashes against the reference.

Assert zero unauthorized admissions.

Pass condition: 1,000/1,000 bitwise-identical decisions and canonical admission states.

References: SQLite transaction isolation (2024–2026); Ascent Datalog (Sahebolamri et al., 2022); RFC 8949 deterministic CBOR (2020), an alternative to custom encoding.

Evidence status: Proposed design, not a published CVIR result. Determinism follows from canonical inputs and pure evaluation under the stated assumptions; 1,000 successful replays establish tested reproducibility, not universal correctness.
