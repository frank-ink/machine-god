# Q
What is the minimal stratified Datalog rule set over capability-ledger rows (entity, rung, evidence_hash, tick) that makes the CVIR promotion ladder MEASURE->FALSIFY->MATCHED_ABLATION->VERIFIED_OUTCOME->CAUSAL_CREDIT->BOUNDED_ADMISSION->REENTRY_TEST->CONTROL_INFLUENCE unsatisfiable to skip under fail-closed invariants, and can a bounded SAT/SMT encoding prove no rung-skipping for a finite tick horizon?

# A
**Minimal Stratified Datalog (Soufflé/Flix syntax):**

```datalog
// Capability ledger: (entity, rung, evidence_hash, tick)
.decl ledger(e: symbol, rung: number, ev: symbol, tick: number)

// Base: MEASURE requires direct measurement receipt
ledger(e, 1, ev, t) :- measured(e, ev, t).

// Sequential promotion: each rung N+1 requires prior rung N at earlier tick
ledger(e, n+1, ev, t) :- ledger(e, n, ev_prev, t_prev), 
                         valid_step(n, n+1, ev_prev, ev),
                         t_prev < t, n < 8.

// Fail-closed invariants (stratified negation)
invalid_skip(e, n, t) :- ledger(e, n, _, t), n > 1, 
                         !ledger(e, n-1, _, _), t' < t.
.fail :- invalid_skip(_, _, _).  // Hard constraint: derivation fails

// Monotonicity: no rung regression
.fail :- ledger(e, n1, _, t1), ledger(e, n2, _, t2), n2 < n1, t2 > t1.
```

**Key properties:** Stratification separates `ledger` (positive) from `invalid_skip` (negation). `valid_step` encodes rung-specific evidence requirements (e.g., FALSIFY needs failed prediction hash; MATCHED_ABLATION needs ablation diff hash). Evidence hashes are opaque — only equality/checkable predicates allowed.

**Bounded SAT/SMT Proof (Z3/CVC5, horizon H):**
- Unroll transition relation `T(e, n, ev, t) → T(e, n+1, ev', t+δ)` for `t ∈ [0,H]`
- Encode skip-freedom: `∀e,n,t: T(e,n+1,t) → ∃t'<t: T(e,n,t')`
- Check `UNSAT` for `∃e,n,t: T(e,n+1,t) ∧ ¬∃t'<t: T(e,n,t')`
- Complexity: O(H·|E|·8) variables; decidable for finite H (Biere et al. 1999; Bradley 2011 IC3/PDR)

**References:** Apt/Blair/Walker *Stratified Datalog* (1988); Soufflé (Jordan et al. 2016); Flix (Madsen et al. 2018); Ryzhyk et al. *Datalog with Constraints* (2013); GRF/CVIR ladder (Gabriel 2026 — framework-internal, **uncertain** public prior art).

**Uncertainty:** Exact `valid_step` predicates depend on GRF evidence ontology (not public). SAT encoding assumes discrete ticks; continuous time requires hybrid encoding (d'Silva et al. 2013).
