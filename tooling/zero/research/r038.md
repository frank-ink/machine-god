What are the most effective, empirically tested architectures for long-horizon autonomous coding agents with persistent memory and self-verification (2024-2026)? Name concrete systems, papers and measured results.

# A
Long-horizon autonomous coding agents: empirical evidence (2024–2026)

Core finding: The strongest experimentally supported pattern combines repository-aware execution, iterative test feedback, selective memory management and independent patch verification. No single architecture has conclusively demonstrated reliable, unattended multi-day software engineering with persistent memory.

2. Persistent memory: counterevidence

VibeMemBench — Fan et al. (2026) evaluates 111 tasks, 90 repositories and 3,634 historical trajectories.

Verified historical memories improved resolution by 1.1–4.5 percentage points in four of five tested solvers.

11 of 12 memory-system/solver combinations failed to outperform memory-disabled baselines.

The benchmark uses SWE-rebench V2, not SWE-bench Verified.

3. Long-horizon difficulty

SWE-bench Pro (2025; revised 2026): Initial controlled evaluations reached 23.3% Pass@1 on substantially harder repository tasks. This is a historical result, not a current performance ceiling.

4. Recommended OMEGA / EntityOS architecture

PLAN → EXECUTE → TEST → CRITIQUE → REPAIR → VERIFY → COMMIT → REMEMBER

Implement:

Persistent task DAG, bounded subtasks and restartable checkpoints.

Sandboxed repository tools with independent acceptance tests.

Critic-based patch selection and bounded retries.

Provenance-aware episodic memory with selective retrieval.

Test-gated commits, immutable execution receipts and deterministic replay.

Paired memory-on/off and verifier-on/off ablations.

Evidence distinction: Execution feedback and independent critics have quantitative support. Persistent memory produces mixed outcomes. Checkpointing, immutable receipts and test-gated commits are defensible engineering controls, but their isolated contribution to multi-day autonomy remains insufficiently measured.

Primary open risk: An agent can preserve state and pass tests while progressively diverging from the original objective.
