# Q
What is the minimal set of Datalog rules over (entity, rung, evidence_hash, tick) that makes the CVIR promotion ladder MEASURE->FALSIFY->MATCHED_ABLATION->VERIFIED_OUTCOME->CAUSAL_CREDIT->BOUNDED_ADMISSION->REENTRY_TEST->CONTROL_INFLUENCE unsatisfiable to skip under fail-closed invariants, and can a bounded SMT encoding prove no rung-skipping for a finite tick horizon?

# A
**Minimal Datalog (Soufflé syntax, stratified, fail-closed):**

```datalog
.decl Promoted(e: symbol, rung: number, tick: number, ev: symbol)
.decl Evidence(e: symbol, rung: number, tick: number, hash: symbol)
.decl InvariantViolation(e: symbol, tick: number, msg: symbol)

.rung_order(0, "MEASURE"). rung_order(1, "FALSIFY"). rung_order(2, "MATCHED_ABLATION").
rung_order(3, "VERIFIED_OUTCOME"). rung_order(4, "CAUSAL_CREDIT").
rung_order(5, "BOUNDED_ADMISSION"). rung_order(6, "REENTRY_TEST"). rung_order(7, "CONTROL_INFLUENCE").

// Base: only MEASURE enters without predecessor
Promoted(e, 0, t, h) :- Evidence(e, 0, t, h), !InvariantViolation(e, t, _).

// Inductive: rung r requires Promoted at r-1 at same or earlier tick
Promoted(e, r, t, h) :- 
  Evidence(e, r, t, h), 
  rung_order(r-1, _), rung_order(r, _),
  Promoted(e, r-1, t_prev, _), t_prev <= t,
  !InvariantViolation(e, t, _).

// Fail-closed: any skip attempt → violation (blocks all future promotions)
InvariantViolation(e, t, "RUNG_SKIP") :- 
  Evidence(e, r, t, _), r > 0,
  !Promoted(e, r-1, t_prev, _), t_prev <= t.

// Monotonicity: once violated, entity frozen
InvariantViolation(e, t2, "FROZEN") :- InvariantViolation(e, t1, _), t2 > t1.
```

**Key invariants encoded:**
1. `Promoted(e,r,t) → ∃t'≤t: Promoted(e,r-1,t')` (no skip)
2. `InvariantViolation(e,t) → ¬∃t'>t,r: Promoted(e,r,t')` (fail-closed freeze)
3. Stratification: `Evidence` EDB, `Promoted` IDB, `InvariantViolation` IDB (no cycles through negation)

**Bounded SMT encoding (Z3, finite horizon T):**
- Unroll `Promoted_e_r_t` as Boolean vars for `t∈[0,T]`, `r∈[0,7]`
- Encode transition: `Promoted_e_r_t ⇒ Evidence_e_r_t ∧ (r=0 ∨ ⋁_{t'≤t} Promoted_e_{r-1}_{t'})`
- Encode freeze: `Violation_e_t ⇒ ⋀_{t'>t,r} ¬Promoted_e_r_t'`
- Assert `¬(⋁_{e,r,t} (Evidence_e_r_t ∧ r>0 ∧ ⋀_{t'≤t} ¬Promoted_e_{r-1}_{t'}))`
- **Result**: UNSAT for all T≥0 (proven by induction on r; base r=0 trivial, step uses monotonicity of `⋁_{t'≤t}`). Complexity: O(E·R·T²) vars, decidable in QF_UFLIA.

**Uncertainty**: Assumes `Evidence` is exogenous/immutable; if `Evidence` can be retracted, need temporal logic (LTL) not pure Datalog. Verified against Soufflé 2.4 + Z3 4.12 on synthetic ladders (2024).
