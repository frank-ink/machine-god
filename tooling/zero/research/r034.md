3. Minimum qualifying experiment

Pre-register ≥200 held-out coding tasks with an independently defined routing oracle.

Compare two paired configurations:

Baseline: Free-pool routing without the local classifier.

Treatment: Identical backends with Qwen2.5-0.5B or Qwen3.5-0.8B classification.

Fix RTX 4090, model hashes, quantization, inference runtime, tool permissions and request budgets.

Publish per-task JSONL containing route predictions, oracle labels, timestamps, escalation decisions, backend responses, test outcomes and errors.

Report p50/p99 E2E latency with bootstrap 95% confidence intervals, confusion matrices, balanced routing accuracy, task-success differences and McNemar significance tests.

Conclusion: Feasibility is supported by adjacent routing research. A statistically validated latency or accuracy improvement for the specified architecture remains unproven. Assigning numerical values would be fabrication.
