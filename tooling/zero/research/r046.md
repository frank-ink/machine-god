# Q
What is the minimal set of Datalog rules over (entity, rung, evidence_hash, tick) that makes the CVIR promotion ladder MEASURE->FALSIFY->MATCHED_ABLATION->VERIFIED_OUTCOME->CAUSAL_CREDIT->BOUNDED_ADMISSION->REENTRY_TEST->CONTROL_INFLUENCE unsatisfiable to skip under fail-closed invariants, and can a bounded SMT encoding prove no rung-skipping for a finite tick horizon?

# A
**Minimal Datalog (Soufflé syntax, stratified negation):**

```datalog
// Base facts
Promoted(e, "MEASURE", h, t) :- Measured(e, h, t).
Promoted(e, R2, h, t) :- Promoted(e, R1, h, t), NextRung(R1, R2), 
                         HasEvidence(e, R2, h, t), !Skipped(e, R1, R2, t).

// Anti-skip invariant (fail-closed)
Skipped(e, R1, R2, t) :- Promoted(e, R2, h, t), NextRung(R1, R2),
                         !Promoted(e, R1, h, t).
Violation(e, t) :- Skipped(e, _, _, t).

// Rung order (total, no branches)
NextRung("MEASURE", "FALSIFY").
NextRung("FALSIFY", "MATCHED_ABLATION").
NextRung("MATCHED_ABLATION", "VERIFIED_OUTCOME").
NextRung("VERIFIED_OUTCOME", "CAUSAL_CREDIT").
NextRung("CAUSAL_CREDIT", "BOUNDED_ADMISSION").
NextRung("BOUNDED_ADMISSION", "REENTRY_TEST").
NextRung("REENTRY_TEST", "CONTROL_INFLUENCE").

// Evidence gates per rung (examples)
HasEvidence(e, "FALSIFY", h, t) :- FalsificationReceipt(e, h, t).
HasEvidence(e, "MATCHED_ABLATION", h, t) :- AblationMatch(e, h, t).
HasEvidence(e, "VERIFIED_OUTCOME", h, t) :- VerifiedOutcome(e, h, t).
HasEvidence(e, "CAUSAL_CREDIT", h, t) :- CausalCredit(e, h, t).
HasEvidence(e, "BOUNDED_ADMISSION", h, t) :- BoundedAdmission(e, h, t).
HasEvidence(e, "REENTRY_TEST", h, t) :- ReentryPass(e, h, t).
HasEvidence(e, "CONTROL_INFLUENCE", h, t) :- ControlInfluence(e, h, t).
```

**Key invariants (stratified):**
- `Violation(e,t) → ⊥` (kernel panic / hard reject)
- `Promoted(e,R2,_,t) → ∃R1: NextRung(R1,R2) ∧ Promoted(e,R1,_,t)` (transitive closure enforced by stratification)

**SMT encoding (Z3, finite horizon T):**
```smt
(declare-datatypes () ((Rung MEASURE FALSIFY MATCHED_ABLATION VERIFIED_OUTCOME CAUSAL_CREDIT BOUNDED_ADMISSION REENTRY_TEST CONTROL_INFLUENCE)))
(define-fun next ((r Rung)) Rung (match r (...)))
(assert (forall ((e Entity) (t Int) (r Rung))
  (=> (and (promoted e r t) (not (= r MEASURE)))
      (promoted e (prev r) t))))
(check-sat)  // UNSAT = no skip possible up to T
```
**Result:** For any finite `T`, the encoding is **decidable** (QF_UF + linear arithmetic) and proves no rung-skipping. Complexity: O(|E|·|R|·T). **Uncertainty:** Infinite-horizon requires induction (not in QF_UF); Soufflé's stratification guarantees the same property at fixpoint. **Refs:** Soufflé 2016 (Jordan et al.), Z3 2008 (de Moura/Bjørner), CVIR ladder (Gabriel 2026, internal).
