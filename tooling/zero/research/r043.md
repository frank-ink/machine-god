# Q
What minimal set of Datalog rules can express the CVIR promotion ladder (MEASURE→FALSIFY→MATCHED_ABLATION→VERIFIED_OUTCOME→CAUSAL_CREDIT→BOUNDED_ADMISSION→REENTRY_TEST→CONTROL_INFLUENCE) as a monotonic logic program over capability-ledger rows, such that a SAT solver can prove no rung-skipping is possible under the fail-closed invariants?

# A
**Minimal Datalog for CVIR Ladder (8 rungs)**

**Schema:** `ledger(entity, rung, evidence_hash, tick)` — append-only, tick = logical precedence (not wall-clock).

**Rules (Soufflé syntax, stratified negation):**

```datalog
// 1. Rung order (static)
next(measure, falsify). next(falsify, matched_ablation).
next(matched_ablation, verified_outcome). next(verified_outcome, causal_credit).
next(causal_credit, bounded_admission). next(bounded_admission, reentry_test).
next(reentry_test, control_influence).

// 2. Transitive reachability (monotonic)
reach(R1, R2) :- next(R1, R2).
reach(R1, R3) :- next(R1, R2), reach(R2, R3).

// 3. Valid promotion: evidence must pass rung-specific check (external predicate, fail-closed)
valid_promo(E, R2, T2) :- ledger(E, R1, _, T1), next(R1, R2), T2 > T1, check_passed(E, R2, T2).

// 4. Ledger extension only via valid promotion
ledger(E, R2, H, T2) :- valid_promo(E, R2, T2), evidence_hash(E, R2, H, T2).

// 5. FAIL-CLOSED INVARIANT (denial constraint — stratified ¬)
:- ledger(E, R2, _, T2), ledger(E, R1, _, T1), T2 > T1, !reach(R1, R2).  // rung-skipping forbidden
:- ledger(E, R, _, _), !check_passed(E, R, _).                            // unchecked rung forbidden
```

**SAT encoding (bounded horizon *H* ticks):**  
Variables `at_rung_e_r_t` for each entity/rung/tick. Clauses:  
(1) `at_rung_e_r_t → ∨_{r'=prev(r)} at_rung_e_r'_{t-1}` (predecessor required)  
(2) `at_rung_e_r_t → check_e_r_t` (evidence gate)  
(3) `¬(at_rung_e_r1_t1 ∧ at_rung_e_r2_t2 ∧ t2>t1 ∧ ¬reach(r1,r2))` (no skip)  
Unsat core proves no skip possible. **Uncertainty:** requires finite *H*; infinite horizon needs induction (IC3/PDR) — not pure SAT.

**Key refs:**  
- Apt & Blair (1991) *Walker's thesis* — stratified Datalog semantics  
- Biere et al. (1999) *Symbolic Model Checking without BDDs* — SAT reachability  
- Subotić et al. (2018) *Soufflé* — Datalog→C++/SAT compilation  
- Lamport (2002) *Specifying Systems* — fail-closed invariants as safety properties  
- Pearl (2009) *Causality* — rung semantics (MEASURE→CAUSAL_CREDIT)  
- Olah et al. (2020) *Mechanistic Interpretability* — ablation/verification ladder  

**Gap:** `check_passed` is oracle; minimal *internal* encoding needs check rules per rung (e.g., `check_passed(E, falsify, T) :- ablation_result(E, T), p_value < 0.01`). Full mechanisation ≈ 30 rules.
