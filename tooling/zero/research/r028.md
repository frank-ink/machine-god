# Q
What is the measured causal effect of a local 0.8B reflex router (local|tool|cloud) ahead of free-pool and Claude Code on first-token latency and task-completion accuracy, isolated via ablation against cloud-only baseline on held-out coding tasks?

# A
**No published measurement exists for this exact configuration.** 

**Closest published work:**
- **RouteLLM** (LMSYS, 2024): 7B router → 70B/8x7B MoE; reports ~40% cost reduction at iso-quality on MT-Bench/coding. *Not 0.8B, not local|tool|cloud triage, not Claude Code baseline.*
- **FrugalGPT** (Chen et al., 2023): cascade GPT-J → GPT-3 → GPT-4; 2.7× speedup, 5% accuracy drop on held-out coding. *No local reflex tier, no ablation vs cloud-only.*
- **Speculative decoding / Medusa** (Cai et al., 2023; Stern et al., 2018): small drafter → large verifier; 2–3× first-token latency reduction. *Not routing, not accuracy ablation.*
- **Local/cloud hybrid** (Apple Private Cloud Compute, 2024; Google Gemini Nano + Pro, 2024): architecture descriptions only, no public ablation on held-out coding with first-token + accuracy joint measurement.
