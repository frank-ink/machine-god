# Q
What is the minimal set of Datalog rules to encode the CVIR promotion ladder (MEASURE -> FALSIFY -> MATCHED_ABLATION -> VERIFIED_OUTCOME -> CAUSAL_CREDIT -> BOUNDED_ADMISSION -> REENTRY_TEST -> CONTROL_INFLUENCE) as executable constraints with automatic violation detection, and has this been implemented in any Rust/TS rule engine (Crepe, Ascent, Datafrog, Souffle bindings) for AI agent governance?

# A
CVIR promotion ladder: executable Datalog governance

Finding: The eight-stage CVIR ladder can be enforced with stratified Datalog, but its exact semantics appear project-specific. I found no documented Rust/TypeScript AI-agent governance implementation of this complete ladder.

1. Minimal rule set

The following is Soufflé-style Datalog. Stage indices are fixed from 0 to 7.

prolog

// MEASURE=0, FALSIFY=1,
// MATCHED_ABLATION=2, VERIFIED_OUTCOME=3,
// CAUSAL_CREDIT=4, BOUNDED_ADMISSION=5,
// REENTRY_TEST=6, CONTROL_INFLUENCE=7

.decl candidate(c:symbol)
.decl evidence(c:symbol, stage:number)
.decl request(c:symbol, stage:number)
.decl valid(c:symbol, stage:number)
.decl missing(c:symbol, stage:number)
.decl violation(c:symbol, stage:number)

valid(c,0) :-
    candidate(c), evidence(c,0).

valid(c,s) :-
    candidate(c),
    evidence(c,s),
    s > 0, s <= 7,
    valid(c,s-1).

missing(c,s) :-
    request(c,s),
    s >= 0, s <= 7,
    !valid(c,s).

violation(c,s) :-
    evidence(c,s),
    s > 0, s <= 7,
    !valid(c,s-1).

violation(c,s) :-
    request(c,s),
    missing(c,s).


Semantics: valid computes the longest contiguous evidence prefix. missing detects attempted promotion without the complete prefix; violation also detects out-of-order evidence.

This minimal encoding assumes evidence is already authenticated and independently validated. The production version must additionally bind evidence to candidate, experiment, epoch, scope and signed provenance; otherwise evidence laundering across experiments remains possible.

3. Production requirements

The example needs .input/.output directives or equivalent host-provided facts to execute.

Add independent predicates for signed receipts, matched controls, causal attribution, scope bounds, authorizations and reentry results. Datalog can verify evidence dependencies, not infer experimental causality from stage labels.

Recommendation: Ascent + SQLite immutable receipts + fail-closed Rust admission gate. TypeScript should expose decisions, not independently reinterpret policy.
