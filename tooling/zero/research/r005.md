# Q
What is the minimal WASM Component Model (WIT) interface definition for a plugin capability manifest that enables versioned capability negotiation between host and plugin without silent capability loss, and has this been fuzzed against adversarial schema drift in any AI agent framework (2024-2026)?

# A
**Minimal WIT for versioned capability negotiation (constructed, not standardized):**

```wit
package plugin:manifest@1.0.0;

interface negotiation {
  record semver { major: u32, minor: u32, patch: u32 }
  record cap { name: string, version: semver, required: bool }
  record manifest { plugin: string, version: semver, provides: list<cap>, requires: list<cap> }
  
  // Host→plugin: host offers caps; plugin returns accepted subset (no silent drop)
  negotiate: func(host-offers: list<cap>) -> result<list<cap>, string>
  
  // Plugin→host: plugin declares manifest; host validates compatibility
  declare: func() -> manifest
}

world plugin { export negotiation }
```

**Key invariants encoded:** explicit `required` flag prevents silent loss; `result<_, string>` forces error handling; `semver` in both directions enables compatibility algebra (host computes `provides ∩ requires` with semver matching).
