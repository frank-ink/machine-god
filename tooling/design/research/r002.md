# Q
What measured results exist for deterministic replay, test-gated commits, and independent critic verification in long-horizon autonomous coding agents with persistent memory (2024-2026)?

# A
Deterministic replay, test gates and independent critics (2024–2026)

Finding: Independent verification and test-based patch filtering have measurable benefits. Deterministic replay is experimentally demonstrated on small failure corpora. Evidence that these mechanisms jointly enable reliable multi-day coding with persistent memory remains insufficient.

2. What is empirically established?

Deterministic replay: Chronicle demonstrates reproducibility of captured nondeterministic boundaries, not reproducibility of arbitrary fresh LLM generations.

Test-gated commits: SWT-Bench provides direct evidence for test-based patch filtering. A separately measured causal improvement from refusing Git commits until tests pass remains unestablished.

Independent critics: OpenHands provides substantial measured gains in selecting successful patches, but the critic is not infallible and results depend on candidate diversity.

Persistent memory: Positive results exist, but cross-repository benefits and statistical robustness remain uncertain.

3. Recommended architecture for OMEGA / EntityOS

Checkpoint → Execute → Test → Independent Critic → Admission Gate → Commit → Persist → Replay

Use immutable SQLite receipts, content-addressed checkpoints, independently executed regression tests, canonical decision hashes, bounded retries and provenance-filtered episodic retrieval.

Critical experiment: Randomized paired memory-on/off and verifier-on/off ablations, with identical models, compute budgets and task sets. Add fault injection, process restarts and deterministic replay.

Main open risk: Agents can consistently replay and verify an internally coherent but incorrectly specified task. Neither reproducibility nor passing tests alone establishes goal correctness.
