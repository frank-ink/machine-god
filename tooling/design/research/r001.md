Main finding: The best-supported architecture combines repository-aware execution, iterative test feedback, selective memory management and independent verification. Published results measure task resolution far more convincingly than reliable, uninterrupted multi-day autonomy.

2. Persistent-memory counterevidence

VibeMemBench — Fan et al. (2026): 111 targets, 90 repositories, 3,634 historical trajectories.

Verified historical experiences sometimes improve task resolution.

11 of 12 tested memory-system/solver combinations failed to outperform memory-disabled baselines.

Benchmark uses SWE-rebench V2, not SWE-bench Verified. 
arXiv

Implication: Memory quality, retrieval relevance and timing matter more than merely accumulating experiences.

3. Harder long-horizon evaluation

SWE-bench Pro (2025/2026): Initial controlled evaluation reported a maximum 23.3% Pass@1, demonstrating substantial remaining difficulty on complex repository tasks. This historical result is not a current performance ceiling. 
Scale Labs

4. Evidence-informed architecture for OMEGA / EntityOS

PLAN → EXECUTE → TEST → CRITIQUE → REPAIR → VERIFY → COMMIT → REMEMBER

Recommended mechanisms:

Checkpointed task DAG with explicit acceptance criteria.

Sandboxed execution and independent regression testing.

Critic-based patch selection with bounded retries.

Episodic and semantic memory with provenance, selective retrieval and memory-on/off ablations.

Test-gated commits, immutable receipts and deterministic rollback/replay.

Evidence distinction: Execution-feedback loops, structured repair and selected memory mechanisms show measurable benefits. Checkpointing and test-gated commits are engineering controls whose isolated contributions to multi-day reliability remain insufficiently quantified.

Open problem: No cited architecture establishes reliable multi-day autonomous coding with consistently beneficial persistent memory, independent verification and safe self-modification simultaneously.
