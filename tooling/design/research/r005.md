# Q
What is the minimal set of semantic color roles (beyond the 6 in research note) needed to express all UI states in a Ratatui TUI while guaranteeing WCAG AA contrast across truecolor, ANSI-256, and 16-color fallbacks without per-terminal calibration?

# A
Ratatui semantic palette: minimal roles (2024–2026)

Finding: Six additional roles provide a practical 12-role palette, assuming the existing six are accent, foreground, background, muted, warning, and error.

However, no finite set of semantic roles can guarantee WCAG AA contrast across arbitrary uncalibrated ANSI-256 and ANSI-16 terminal palettes. Roles define meaning, not physical colors. Terminal themes can redefine ANSI RGB values.

These 12 roles cover common textual, interactive, selection, focus and status states. They are a practical minimum, not a mathematically proven minimum for every conceivable UI.

Additional roles such as disabled, hover, info, overlay and surface_alt are optional. Disabled and hover states should also have non-color cues.

2. WCAG AA contrast thresholds

WCAG 2.2 (W3C, 2023) and WCAG2ICT (2024) specify:

Normal text: ≥4.5:1

Large text: ≥3:1

Essential non-text UI indicators: ≥3:1

Meaning must remain understandable without color alone.

4. Deterministic palette audit

For each Theme × ColorMode × UIState:

Resolve all foreground/background pairs.

Check contrast after color quantization.

Reject hardcoded colors outside the palette registry.

Snapshot rendered ratatui::buffer::Buffer output.

Verify focus, selection and error states using non-color markers.

Recommended contract:

contrast(text,bg) ≥ 4.5 and contrast(essential_ui,adjacent) ≥ 3.0

These are enforceable only when effective colors are known.

Conclusion: Twelve semantic roles suffice for a compact conventional TUI. Universal WCAG AA compliance across uncalibrated terminals is impossible to guarantee. For strict accessibility assurance, require a known palette or verified terminal capabilities; otherwise provide a robust monochrome fallback.

Evidence status: Standards-backed contrast requirements and documented terminal APIs, not an empirically established universal 12-role minimum.
